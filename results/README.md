# Results Directory

Preprocessed data and evaluation results are saved here.

## Preprocessing Output

- `X_train.npy` - Training windows
- `X_val.npy` - Validation windows
- `X_test.npy` - Test windows
- `scaler_params.json` - MinMax scaler parameters
- `signal_order.json` - Correlation-based signal ordering

## Evaluation Output

- `evaluation_results.npy` - Detection metrics
